## 这是什么

键盘厂商的驱动只能给你几种固定的灯效，改一点参数就得到处点。这个东西把控制权拿回来：

- 浏览器通过 **WebHID** 直接连键盘，**每一颗灯**单独寻址，逐帧推送 RGB 数据；
- 页面上同时跑一份**实时预览**，边调边看，不用等键盘反应；
- **24 种效果**，从跑马灯、等离子、生命游戏到烟花、贪吃蛇，全部是逐灯计算的二维动画；
- 纯单文件 HTML，**没有构建、没有 CDN、没有后端**，断网也能用。

| **实时预览**    | 与键盘同帧的 2D 画布预览，可切换机型布局                                                                                 |
| **亮度 / 帧率** | 亮度 5–100（默认 100），推帧 10–60 Hz（默认 25 Hz）                                                                 |
| **中英文界面**   | 右上角一键切换，选择记在 `localStorage`                                                                            |
| **自定义灯光编辑器** | 独立分页，键盘图上**拖框多选**一键填色 / 渐变 / 预设；改动**自动保存**进板载自定义槽 1–5，关闭网页键盘仍保持这套配色                |
| **写死到自定义一** | 把当前这一帧的**静态 RGB** 写进板载槽（等效于编辑器的「写入自定义 1」），掉电保留                                          |
| **诊断日志**    | 从握手到每一包的状态都留痕，出问题不用猜                                                                                   |
| **零依赖**     | 单个 HTML 文件，双击即开                                                                                        |

> **关于「写死到自定义一」**：板载槽只有一帧的容量（384 字节 = 128 键 × RGB888），写进去的是**按下按钮那一瞬间的静态画面，不是动画**。想让键盘自己跑动画，得靠固件支持，浏览器推流做不到。

## 快速开始

1. 用 **Chrome / Edge**（桌面版 89+）打开 `index.html`。  
   Safari、Firefox 不支持 WebHID，手机上也不行。
2. 点 **「连接键盘」**，在浏览器弹窗里选中你的键盘（同一台设备只需授权一次）。
3. 点 **「开启灯光通道」**，键盘进入自定义模式，页面开始推帧。
4. 左侧挑效果、调亮度与帧率。
5. 结束前点 **「停止并交还固件」**——把 `lightMode` 还原成连接前的值，否则键盘会停在自定义模式，帧一停就全黑。

如果页面打不开设备、或连上了却没反应，先看页面底部的诊断日志，通常能直接看出是哪一步被固件拒了。

## 自定义灯光编辑器

官方驱动改自定义灯光只能「选一个颜色、点一颗键」，一颗一颗填。这个页面把它换成了拖框选区：

1. 顶部切到 **「自定义灯光」** 分页（编辑器独占推流通道，须先点「开启灯光通道」，没开会自动锁住并给出解锁按钮）。
2. 在键盘图上 **按住拖出一个框**，框到的键全部选中（白色描边）。`Shift` 拖 = 追加，`Ctrl` 拖 = 反选，单击 = 只选一颗，点空白 = 取消。
3. 在右侧点一个颜色 → **立刻填进选区**（已选好区时，点色块就是填充）。也可以：
   - **渐变**：水平 / 垂直 / 径向，从主色过渡到末端色
   - **预设**：彩虹横扫、彩虹纵扫、日落、海洋、极光、赛博、暖白、随机
   - **微调**：色相 ±15°、亮一档 / 暗一档、反色、同色补满整行
   - `Enter` 填主色，`Del` 熄灭，`Ctrl+Z / Ctrl+Y` 撤销重做，`Ctrl+A` 全选，`Esc` 取消选区
4. 选区不满足时用左边的 **补满整行 / 补满整列 / 全选 / 反选** 修正。
5. **改动自动保存**：每次改动停约 1.2 秒后，画布会自动写进当前板载槽（`0x23 / 0x25 / 0x27 / 0x29 / 0x2B`，对应驱动里的自定义灯光 1–5），掉电保留；也可以点 **「立即保存」** 马上落盘。

**槽位切换**：点顶部的数字 1–5 即可切槽——自动载入该槽现有配色、把键盘也切过去显示；旧槽没存完的修改会先补存再切走。

**为什么关闭网页键盘还在显示这套配色**：进入编辑器时页面会把固件「当前灯效」指向该自定义槽（`lightMode=253` + `lightCustomIndex=槽号`），编辑期间持续推帧（`0x2E`，RGB565）只是覆盖显示；帧流一断（切分页、关网页、拔线），固件就按槽里已保存的静态配色渲染，而不是退回原厂动画。

**读取**：`0x22` 是「读自定义一」，已在 WAVE75 上实测；`0x24 / 0x26 / 0x28 / 0x2A` 是按同规律推断的其它四个槽，读不到时画布留空并提示，不会静默失败。

**导入 / 导出**：导出的是本页的 JSON（128 个色值 + 每个键的 `lightIndex`）；导入除了认自己导出的文件，也认驱动导出的 `rdr-profile-*.json`（读 `keyItemColor` 里的 `lightIndex` 和 `color`），所以可以直接把驱动里存的那套配色搬过来改。

## 技术说明

**协议格式**（RDR 系私有协议，65 字节定长包）

```
reportId(0) | 0xAA | cmd | offset(2, LE) | len | 00 00 | status | data[56]
```

- `status`：`0x55` 成功，`0x0F` 固件拒绝（回包第 8 字节）。
- 逐键推帧走 **`0x2E SET_LIGHT_SYNC`**，每颗灯 **RGB565**（2 字节小端），整帧按 56 字节分块。  
  以 WAVE75 的 82 颗灯为例：164 字节拆成 56 + 56 + 52，共 3 包。
- 结束用 `0x2F CLOSE_SYNC`；`0x10 START` / `0x11 STOP_COMM` 管通信开关，`0x14/0x15` 读写灯光模式，`0x12` 取设备信息。
- **`0x2E` 只写 RAM**：帧一停，键盘立刻回落到槽内的静态色。若想落盘，用 **`0x23 SET_USERLIGHT_1`** 写 384 字节 RGB888（128 键 × 1 帧）进 Flash。

**灯号映射的两个坑**：

1. **46 号是空号**。固件承认的灯号是 `0..81` 共 82 个位置，但没有任何键映射到 46 号——真实灯珠只有 81 颗，`A` 键从 47 开始。所以布局里 81 个键落在 `0..45` + `47..81`，中间跳过一格。这个结论有**两个独立来源**互相印证：固件 `0x32 GET_LIGHT_MATRIX`（读灯矩阵）返回的 128 条映射表里没有 46，官方驱动「配置管理 → 导出」的 `rdr-profile-*.json` 里 81 个键的 `keyInfos[].lightIndex` 也没有 46（`Caps Lock = 45`、`A = 47`）。
2. **自定义槽的 384 字节按「灯号」排，不按 `0x32` 的槽位索引排**。`0x22`（读/写自定义槽）和 `0x34`（读当前输出）回的都是 128 × RGB888，但第 i 个三元组就是灯号 i 的颜色，**不需要**过 `0x32` 的映射表。判断方法：把读回的色值分别按两种寻址还原，再量相邻键的色差——按灯号还原时平均色差 41、按槽位索引还原时平均色差 69 且在 `Delete-Home`、`]-\\` 处出现 500+ 的断层。

用官方导出表核对页面布局（改布局后跑一次）：

```bash
node verify_against_profile.js rdr-profile-1.json WAVE75
```

它会逐键比对键集合、`lightIndex`、灯号覆盖范围，并打印官方物理顺序表；有任何差异都会返回非 0。

偏移量不能靠推理，必须读 `0x32`、拿官方导出表或真机逐个点亮确认。

## 已知限制

- **板载存不了动画**：自定义槽只有一帧的容量，动画必须靠页面持续推流。
- **一次只能一个页面占用**：另一个标签页连着同一把键盘时，这里会推帧失败。
- **浏览器限制**：只有 Chromium 系桌面浏览器支持 WebHID；每次会话的授权弹窗无法绕过。
- **布局靠实测**：新机型大概率需要重新标灯号（点一颗、看哪颗亮），没有捷径。
